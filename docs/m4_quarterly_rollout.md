## 2.4.2. Rollout-симуляция на quarterly рядах (M4) — адаптировано

В исходном ТЗ использовались MODWT-разложение и гибриды вида TimesNet/N-BEATS + бейзлайн на деталях.
В рамках текущего исследования эти элементы исключены: **не используем MODWT, TimesNet, N-BEATS**.
Вместо этого для quarterly рядов выполняется стандартный анализ с **Holt–Winters (ETS) декомпозицией**
на компоненты (тренд/сезонность/остаток), построением **наивного** прогноза и **rollout-прогноза**
(итеративного разворачивания по одному шагу).

### Данные и выбор рядов

- Рассматривается категория `quarterly` набора M4 (`H=8`, сезонный период `P=4`).
- Для иллюстрации выбираются **3 случайных ряда** из `quarterly` (фиксируем seed для воспроизводимости).
  При `seed=42` выбранные ряды: `Q15710`, `Q2142`, `Q18575`.

### Стандартный анализ для каждого ряда

Для каждого выбранного ряда строятся следующие диагностические графики:

1) **Исходный ряд (train/test)** + ACF/PACF по train.

2) **Декомпозиция Holt–Winters**:
   - *Trend-like* (базовая компонента без сезонности),
   - *Seasonal* (сезонная компонента),
   - *Residual* (остаток; в используемой схеме — мультипликативное отношение `y/base`).

3) **Наивный прогноз** (seasonal naive): повторение последних `P=4` наблюдений на горизонт `H=8`.

4) **Rollout-прогноз**: прогноз строится рекурсивно по одному шагу вперёд,
   каждый новый предикт добавляется в конец окна длиной `L`, а самое старое значение удаляется.

### Как воспроизвести (код)

Запуск готового сценария для 3 случайных quarterly рядов:

```bash
python eval_m4.py --config configs/m4_quarterly_rollout.json
```

Графики сохраняются в `src/outputs/m4_eval/viz/`:

- `01_raw_series/` — исходный ряд (train/test)
- `02_acf_pacf/` — ACF/PACF по train
- `03_hw_pair/` — ряд + HW бейзлайн и компонент `y/base`
- `04_hw_components/` — тренд / сезонность / остаток
- `05_forecast_zoom/`, `06_forecast_full/`, `07_forecast_test_only/` — прогнозы (включая `Naive`)
- `09_simulation_full/` — rollout-симуляция на полном ряде (если включено в конфиге)

Метрики по каждому ряду сохраняются в `src/outputs/m4_eval/metrics.csv`.
